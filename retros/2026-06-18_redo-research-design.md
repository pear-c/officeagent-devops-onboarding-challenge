## 1. AI를 어떻게 썼나 (프롬프트 원문 요지)

조사를 **3갈래 병렬 서브에이전트**로 돌렸다. 각 에이전트에 준 지시의 핵심:

- **NHN 조사**: "AWS 8개 컴포넌트(VPC·RDS PostgreSQL·S3·KMS·…)를 NHN 공식 docs(docs.nhncloud.com)에서 대응 서비스명+URL로 찾아라. **특히 RDS PostgreSQL의 무중단 마이그레이션/logical replication 지원 여부**(4h 제약 핵심)를 파고, 못 찾으면 지어내지 말고 '미확인'으로."
- **법령·CSAP 조사**: "law.go.kr 원문·과기정통부 고시·KISA로 클라우드법 §18·§23의2, 개보법 §24·§28의2·§29, 정보통신망법 §25, CSAP 등급제를 확인. 조문 번호·제목을 정확히."
- **OpenStack 조사**: "AWS/NHN 관리형을 오픈스택 자체구축으로 대응할 때 Neutron/Cinder/Swift/Keystone/Barbican/Trove 매핑 + 운영 부담."

세 에이전트 모두 **"확인 못 한 항목은 지어내지 말고 미확인으로 표시 + 이유"**를 강제했다 — 이게 결과 신뢰도를 좌우했다.

## 2. AI 응답을 그대로 받지 않은 결정 (비판·수정)

### 2-1. ★ wiki의 법령 인용 3건이 틀렸다 → 교정

내가 조사 지시서에 적은 조문 번호(애초에 wiki에서 가져온 것)가 **실제 법령과 달랐고**, 법령 에이전트가 이를 반증했다. 그대로 베꼈으면 Q&A 1차자료 축에서 바로 깨졌을 지점:

| 초안(wiki, 틀림) | 교정 |
|------------------|------|
| 클라우드법 §18 = 데이터 처리 위치 | §18=「공정한 경쟁 환경 조성」, 데이터는 **§27** |
| 개보법 국외이전 §28의2 | **§28의8** (2023-09-15 개정으로 이동) |
| 망분리 = 정보통신망법 §25 | **개보법 시행령 §48의2** (망법→개보법 이관, 2025 위험기반) |

→ **교훈**: wiki는 출발점일 뿐이고, 1차 자료로 교차검증해야 한다는 PRD 원칙을 몸으로 확인. 설계서 §8.1에 "교정 이력" 표로 박제해 오히려 강점으로 만들었다.

### 2-2. "NHN DMS" 함정 — AI 검색이 다른 회사 문서를 물어옴

NHN RDS 무중단 이전을 찾다가 검색이 **"DB Migration Service"**를 물어왔다. 그대로 받았으면 "NHN은 무중단 도구 있음"으로 잘못 결론 낼 뻔했다. 출처 도메인을 확인하니 `guide.ncloud-docs.com` = **Naver Cloud(NCP)**, NHN이 아니었다. → 제외하고 "NHN 공식은 pg_dump뿐, DMS 미확인"으로 정직하게 기록. 이게 설계의 **최대 위험(가장 큰 미해결)**이 됐다.

## 3. 가장 막혔던 지점과 돌파

**WebFetch(웹 페이지 직접 열람)가 이 작업 환경에서 차단됨.** law.go.kr·docs.nhncloud.com·docs.openstack.org 원문을 직접 정독·캡처할 수 없었다.

- **돌파**: 숨기지 않고, WebSearch 스니펫에서 확인된 사실만 기재 + **신뢰도 등급 *[확인됨]/[부분확인]/[미확인]*** 을 모든 인용에 붙였다. 원문 대조가 필요한 항목은 "캡처 단계 보강 대상"으로 명시.
- **판단**: PRD가 "모른다"를 감점하지 않고 **리스크+검증계획이 있으면 가산**한다는 점을 활용. 환경 한계를 정직하게 드러낸 것이 오히려 솔직성 점수에 부합한다고 봤다.

## 4. KPT

**Keep**
- 조사를 도메인별 병렬 에이전트로 분리 + "미확인은 지어내지 말 것" 강제 → 신뢰도 확보.
- 의사결정마다 6요소(결론·근거·대안·트레이드오프·리스크·검증계획) 박스로 잠정 결론을 강제.
- 검증 시나리오에 "기대 출력"을 추상문이 아니라 구체값(행수·MD5·diff 0줄·HTTP 000/200·grep 0)으로.

**Problem**
- WebFetch 차단으로 1차 자료 원문 캡처를 못 했다(스니펫 의존).
- DB 용량을 모른 채 4h 합산을 "≤50GB 가정"으로 둠 — 실측 전엔 잠정.
- 비용 정량 비교(§5.1)를 NHN 단가표 미수집으로 보류.

**Try**
- v2에서 브라우저로 1차 자료 원문 직접 열람 + 캡처 보강.
- infra/ Terraform skeleton 작성 → VALIDATION A-1 `terraform validate`를 실제 실행 증거로.
- NHN 기술지원에 `wal_level=logical` 허용 여부 문의(B-1 2차안 가능성 확정).
